# 📒 Dev-Notes

Dev-Notes é uma aplicação web desenvolvida para criar, visualizar e gerenciar anotações de forma simples e eficiente. O projeto foi construído com foco no aprendizado e aplicação prática de manipulação do DOM, eventos e funções em JavaScript, simulando o funcionamento de uma aplicação real no navegador.

Este projeto reforça conceitos fundamentais do desenvolvimento Front-end, incluindo interação dinâmica com o usuário, atualização em tempo real da interface e organização de código utilizando boas práticas.

# 🚀 Funcionalidades

## ➕ Criar novas anotações dinamicamente

## 📝 Editar conteúdo diretamente na interface

## ❌ Remover anotações

## ⚡ Atualização instantânea usando manipulação do DOM

## 🎯 Interações baseadas em eventos do JavaScript

# 🧠 Objetivo do Projeto

O principal objetivo é praticar e consolidar conhecimentos essenciais de Front-end, como:

Manipulação do DOM

Uso de Event Listeners

Estruturação de funções em JavaScript

Criação de interfaces interativas sem frameworks

Este projeto simula o comportamento de aplicações modernas, fortalecendo a base necessária antes do uso de bibliotecas como React.
